# 🧊 Ice-TEMBOX

Alat monitoring suhu palka/coolbox kapal nelayan berbasis IoT biar es batu nggak keburu cair dan ikan tetap segar sampai pelelangan.

---

### Masalah di Lapangan
Nelayan sering kali baru sadar es balok di palka sudah habis pas kapal mau bersandar. Akibatnya:
* Ikan keburu hangat, rusak, dan memicu racun histamin.
* Harga tangkapan jatuh di Tempat Pelelangan Ikan (TPI) karena kualitas dianggap jelek.
* ABK harus bolak-balik buka tutup palka cuma buat ngecek es, yang ujung-ujungnya malah bikin hawa dingin keluar.

Ice-TEMBOX dibuat buat ngawasin suhu palka secara otomatis tanpa perlu sering dibongkar manual.
